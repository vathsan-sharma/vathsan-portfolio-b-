# Vathsan Sharma · Portfolio

Personal portfolio for Vathsan Sharma, built with React and Next.js.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Structure

```
app/                  Next.js app router: layout, page, global styles
components/           One file per section of the homepage
public/images/        Images served by the site (portrait cutout)
design-assets/        Original, unedited design files (not served)
docs/                 Reference mockups used to plan the design
archive/              Earlier drafts, kept for reference only
```

## Placeholders

Items in square brackets, such as `[confirm]` or `[link]`, are waiting on
confirmation: the 200+ and 500+ figures, client permission, the booking link,
and the robot/drone photo slot.

## Design

- Palette: light gray `#F5F5F7`, ink `#1D1D1F`, black `#000000`, gray `#86868B`
- Type: Inter, weights 300 / 400 / 500
- Motion: entrance animations and scroll reveals; all motion is turned off for
  visitors who prefer reduced motion.
